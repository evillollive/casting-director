1Prep this week's prompt

The scan itself is an AI job: it needs live web search and judgment, so it runs in your AI assistant, not here. This tab builds the exact prompt to paste in, with your do-not-resurface list from the Rolodex tab, this week's TUNING, and your recent taste log injected automatically.

  1. Fill in TUNING below for this week's focus. It is remembered between runs.
  2. Click Copy prompt.
  3. Paste it into an AI assistant with web search ON (or a browsing agent) and run it.
  4. Bring the shortlist it returns back to the Evaluate a run tab.
