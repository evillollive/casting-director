# Tier 2 interface provenance

The Tier 2 application remains an original AGPL-3.0 implementation whose
editorial contract, domain model, and runtime boundaries are defined by this
repository.

The interface architecture was informed by a private internal prototype:

- Repository: `basilshadid/casting-director`
- Reviewed revision: `4fb06e7c49897fb0557c650bda4f17dd4f65ba3e`
- Concepts adapted: data-driven workspace navigation, a sticky translucent
  header, inline configuration readiness, compact status treatments, scan
  lifecycle presentation, and responsive internal-tool layouts.

No donor prompt, rubric, evaluator, worker, source connector, schema, provider
integration, or source code was copied. The donor checkout had no license file,
so the implementation in this repository uses independently authored
components and styles while recording the design reference for provenance.

The canonical editorial artifacts remain:

- `prompts/tier0-weekly-scan.md`
- `rubric.md`
- `tools/casting_eval.py`
